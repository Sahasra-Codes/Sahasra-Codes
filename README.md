# hi, i'm sahasra.

**imagination, with intention.**

I'm a computer science student drawn to the space where **design, engineering, and human experience** meet.

I like the idea that software can be both technically thoughtful and genuinely delightful. That a tiny interaction can make a product feel more human. That the best interfaces aren't just beautiful — they're intuitive, purposeful, and built around the people using them.

I started building because I loved imagining what a product *could* be. Somewhere between designing interfaces, connecting APIs, and debugging code that absolutely refused to work, I discovered something else: I really love understanding **how things work**.

Now I'm exploring product engineering — the intersection of thoughtful design and the technical decisions that bring an idea to life.

I care about the little details, but I'm increasingly fascinated by everything underneath them: the systems, algorithms, and logic that make software possible.

**Currently:** building full-stack projects, learning machine learning from the fundamentals, and getting better at turning ambitious ideas into working software.

---

### a little about how i build

**01 / imagine freely.**  
Good ideas often start with curiosity. I like asking *what if?* before worrying about *how?*

**02 / design intentionally.**  
Every interaction should have a reason to exist. I want to build things that feel considered, not just decorated.

**03 / engineer thoughtfully.**  
A good idea deserves more than a convincing prototype. I'm learning to understand the architecture, logic, and tradeoffs that make it real.

**04 / stay curious.**  
The more I learn about software, the more I want to understand. Lately, that's meant exploring machine learning, algorithms, and what happens beneath the abstractions.

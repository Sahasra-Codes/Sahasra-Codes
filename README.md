## About Me

I'm a Computer Science student at UT Dallas who likes owning a product from the first sketch to the last deploy. I'm an all-rounded engineer: I build frontends, I go full-stack when a project needs it, and I design the experience in Figma before I write a line of code.

I've spent real time on UI/UX design and on API integration, the part where a polished interface meets a messy real-world system and has to behave. Being comfortable on both sides means I can see where a design will break in code, and where the code is making life harder for the person using it.

What ties it together is human-centered product engineering. I care less about shiny tech and more about the person on the other end: is it clear, is it fast, does it make sense?

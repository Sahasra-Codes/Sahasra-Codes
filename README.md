## ✨ About Me

I'm a CS student who loves building software people actually enjoy using. I like the whole loop: sketching an idea in Figma, shipping it in React, and wiring up the backend that makes it feel alive.

- 🎨 I design in **Figma** and build in **React + TypeScript**
- 🤖 I'm exploring **AI-powered apps** and how complex systems fit together
- 🌱 Currently learning **FastAPI**, **Python backends**, and building real API pipelines
- 🧠 I care about **human-centered product design** and making tech feel approachable
- 📚 Co-authored a published children's STEM book, *Maddie's STEMAventure*, through Girls Who Code
